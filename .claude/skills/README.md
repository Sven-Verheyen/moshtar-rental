# Skills

De skills in deze map (behalve eventuele eigen skills) komen uit
[mattpocock/skills](https://github.com/mattpocock/skills), MIT-licentie
(zie `LICENSE-mattpocock-skills`). Overgenomen: alle skills uit `skills/engineering`
en `skills/productivity` op commit `49dd158` (9 oktober 2026), zonder de
Codex-specifieke `agents/openai.yaml`-bestanden.

Begin met `/ask-matt` om te zien welke skill of flow bij je situatie past.
De gebruikelijke flow voor een nieuwe feature:
`/grill-with-docs` → `/to-spec` → `/to-tickets` → `/implement` (met `/tdd` en `/code-review`).

Bijwerken: kopieer de nieuwe versie van de skill-mappen uit de upstream repo
hierheen en pas de commit hierboven aan.
